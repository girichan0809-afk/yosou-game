# 3チーム対抗 予想ゲーム

## GitHubへのアップロード
このZIPをWindowsで右クリックして「すべて展開」してください。
展開した `yosou-game` フォルダーの中にある `index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダーを、GitHubリポジトリのルートにアップロードします。

## 機能
- 3チーム・全5問
- 問題名、単位、正解、各チームの予想を入力
- 5秒カウントダウン
- 絶対誤差による各問の順位
- 5問の誤差合計による総合順位
- ブラウザー内への自動保存
- CSV形式で結果を保存
- Service Workerによるオフライン起動対応

## 注意
ゲーム記録は、その端末・ブラウザー内に保存されます。ブラウザーのデータを消去すると記録も消える場合があります。重要な結果はCSVで保存してください。
